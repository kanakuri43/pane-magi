# pane-magi 開発・公開計画

## 構成方針

| 要素 | 選択 |
|------|------|
| フロント | バニラJS（現状継続）|
| DB | Supabase (PostgreSQL) |
| 写真ストレージ | Supabase Storage |
| ホスティング | Netlify（無料）|
| 認証 | 管理側のみ簡易パスワード認証 |

## アプリ構成

- **客用アプリ**（認証なし）: 店舗選択 → 日付選択 → 出勤スタッフ一覧
- **管理者用アプリ**（簡易認証あり）: 出勤登録 + スタッフプロフィール管理
